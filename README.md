# UNP_VAC_PROJECT_GRAND_HORIZON_HOSPITALITY_ANALYSIS_USING_MS_EXCEL

This is my Business Data Analysis Project based on the provided company, GrandHorizon Hotels & Resorts Ltd. I, Kritika Yadav, worked on this project to understand the company's objectives and analyse its business data using Microsoft Excel.

I started by cleaning and preprocessing the dataset, removing duplicate records, handling missing values, and correcting inconsistent values and errors. After preparing the data, I created 5 Pivot Tables and 5 Pivot Charts to present meaningful business insights.

I further performed 3 statistical tests, along with regression and correlation analysis, to understand relationships between different variables and draw conclusions from the data.

After completing all the analysis manually, I also used AI tools with structured prompts to perform the same tasks and compare the results.

Through this project, I gained practical experience in data cleaning, Excel, statistical analysis, data interpretation and AI-assisted analytics. It helped me understand how raw business data can be transformed into meaningful insights to support better decision-making.
